# Agentic systems are struggling to scale (this should feel familiar)

## Core Question

Why do agentic systems struggle to scale to complex engineering challenges?

## Main Idea

Agentic systems succeed in isolation but fail in coordination.

## Key Points

- Strong at:
  - generating code
  - summarizing information
- Weak at:
  - multi-step workflows
  - coordination across roles
  - long-lived context

## Parallel with Humans

- A developer can write a function
- But without structure, cannot ship a product

> This is not surprising — humans behave the same way.

## Misconception

Scaling = more agents or better models

## Reality

Scaling = better structure

## Hook

“Why can an agent write a function, but fail to ship a feature?”

## Transition

> Engineering teams don’t scale by thinking harder. They scale by structuring information.
